Use MS_Restart.R for full R code used in project. This contains annotations/instructions and also calls to additional code files when needed.

For SCING, use qsub_SCING_MSMC.sh and run_scing_MSMC.py

For wKDA, use qsub_wKDA_MSMC.sh and wKDA_after_SCING_MS.R

To preprocess GWAS files, use shell_preprocess_gwas.sh and preprocess_gwas.py as well as shell_filestxt_gwas.sh and filestxt_gwas.py

For MDF, use mdprune and MDF.bash

For MSEA, use MSEA.sh and run_msea.R

For SATURN, follow SATURN.docx

Following SATURN, use extract_macrogenes.py
